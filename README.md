## 🤔 About Me

Hi, I'm Wagner! 👋

I'm a Software Engineer with a Bachelor's degree in Informatics and Computing Engineering and a Master's degree in Electrical and Computer Engineering from the University of Porto (FEUP).

My work focuses on Artificial Intelligence, particularly Large Language Models (LLMs), Multi-Agent Systems, RAG, and Backend Development.

For my Master's thesis (18/20), I developed MARS, a multi-agent LLM framework designed to automate the reproduction and validation of scientific algorithms.

I'm passionate about building practical AI solutions and continuously improving my knowledge of Machine Learning and Software Engineering.

## 🚀 Featured Projects

### 🤖 [LLM from Scratch](https://github.com/WagnerTPedrosa/llm-from-scratch)
Implementation of GPT-2 in PyTorch, following Sebastian Raschka's *Build a Large Language Model (From Scratch)*. Covers tokenization, attention mechanisms, Transformer architecture, pretraining, and fine-tuning for classification and instruction following.

**Tech Stack:** Python, PyTorch, Transformers, GPT-2

### 📡 [WiFi OFDM Receiver](https://github.com/WagnerTPedrosa/wifi-ofdm-receiver)
IEEE 802.11a WiFi receiver using GNU Radio and PlutoSDR, featuring real-time packet decoding, automatic channel scanning, signal analysis, and Wireshark integration.

**Tech Stack:** Python, GNU Radio, PlutoSDR, OFDM

### ✈️ [ADS-B Aircraft Tracking System](https://github.com/WagnerTPedrosa/ads-b-aircraft-tracking-system)
Real-time aircraft tracking system using a custom ADS-B antenna and RTL-SDR to receive and decode aircraft signals, with a REST API for data visualization.

**Tech Stack:** C, RTL-SDR, ADS-B, REST API

### 🎮 [2D Dungeon Crawler](https://github.com/WagnerTPedrosa/dungeon-crawler-2D-game)
A Java-based dungeon crawler featuring combat mechanics, enemy AI, inventory management, equipment upgrades, and progressive levels.

**Tech Stack:** Java, OOP, Game Development, Testing
